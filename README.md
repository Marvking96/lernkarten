# Lernkarten

Karteikarten-App (Web-App/PWA) – Frage vorne, Antwort hinten.
Läuft über GitHub Pages aus dem Ordner `docs`.

**Wichtig:** Die Kartendateien (`karten_*.json`) gehören NICHT in dieses Repository –
sie werden direkt in der App importiert und bleiben nur auf dem Handy.

App-Update: Dateien in `docs` ersetzen und in `docs/sw.js` die `VERSION` hochzählen
(z. B. `lernkarten-v2`), damit die Handys die neue Version laden.
